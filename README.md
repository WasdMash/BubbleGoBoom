BubbleGoBoom is a 2D medieval-themed dungeon-crawler created in the Unity game engine using C#.
This started as a project from the Global Game Jam 2025 from the theme of bubbles.
In this game, you fight through swarms of dirty enemies (from slime to dirt and all sorts of filth), cleansing them with your trusty clean-up kit.
I aim for this to make this game my first indie-released game on Steam, implementing procedural dungeon creation, dialogue and inventory systems.

This game will be run as a .exe file on Windows (select the 'Run Anyway' section when prompted by the OS).
